# Work Standards

A comprehensive, reusable set of software development standards.

## Overview

These standards provide consistent guidelines for software projects, covering:

- **Core Standards**: Naming, project structure, testing, documentation
- **Build & CI/CD**: Makefiles, GitHub workflows
- **Interfaces**: CLI, services, APIs, user interfaces

## Quick Start

Browse the standards at [standards/index.md](standards/index.md).

To adopt these standards in your project:

```markdown
This project follows the [Work Standards](https://github.com/thelenorith/sandbox/tree/main/standards).
```

## Guiding Principles

1. **Consistency** - All projects follow the same patterns
2. **Simplicity** - Minimal configuration, sensible defaults
3. **Automation** - CI catches issues before merge
4. **Discoverability** - Standard locations for everything
5. **Industry Alignment** - Build on established standards
