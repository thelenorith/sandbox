# Mirrorless Camera Evaluation Criteria

## 1. Use Case

Quality mirrorless camera body + zoom lens for photographing people: portraits and burst shots to capture fleeting expressions. **Weight is a critical factor** in system selection.

## 2. Sensor Size Classes

| Format | Sensor Size | Crop Factor |
|--------|------------|-------------|
| Micro Four Thirds (MFT) | 17.3 x 13mm | 2x |
| APS-C | ~23.5 x 15.6mm | 1.5x (1.6x Canon) |
| Full Frame (FF) | 36 x 24mm | 1x |

**Crop factor and equivalent focal length:** Multiply the actual focal length by the crop factor to get the FF-equivalent field of view. This means smaller sensors achieve the same framing with physically shorter lenses. Shorter focal lengths require smaller glass elements, which means lighter lenses.

Example — the classic 85mm FF portrait focal length:
- APS-C: ~56mm lens gives the same field of view
- MFT: ~42mm lens gives the same field of view

## 3. Camera Body Criteria

Each camera body is evaluated on:

| Criterion | Unit / Format |
|-----------|--------------|
| Cost | USD, body only |
| Weight | grams, body only |
| Sensor size | FF / APS-C / MFT |
| Resolution | megapixels |
| Burst rate | fps (mechanical shutter / electronic shutter) |
| Autofocus | Eye/face detection capability, tracking performance |
| EVF quality | Resolution (dots), refresh rate (Hz) |
| IBIS | Yes/No + rated stops of stabilization |
| Battery life | CIPA rating, shots per charge |

## 4. Lens Criteria

Each lens is evaluated on:

| Criterion | Unit / Format |
|-----------|--------------|
| Cost | USD |
| Weight | grams |
| Aperture | max (e.g., f/1.4, f/2.8) |
| Optical quality | Sharpness, bokeh character (qualitative) |
| AF speed | Fast / Moderate / Slow |
| Weather sealing | Yes / No |

## 5. Standard Lens Comparisons

To compare across sensor systems, we evaluate lenses at these FF-equivalent focal lengths:

**Prime lenses (3 categories):**
- **35mm equiv** — environmental portrait, street
- **50mm equiv** — standard portrait
- **85mm equiv** — classic portrait, headshot

**Zoom lens (1 category):**
- **24-70mm equiv** — versatile portrait zoom

## 6. Smaller Sensor Weight Advantage

The physics are straightforward: a smaller sensor requires a shorter focal length to achieve the same field of view. Shorter focal lengths mean smaller diameter glass elements and shorter lens barrels. The result is a lighter lens. The body itself is also typically smaller and lighter because it houses a smaller sensor and mirror box (or sensor assembly).

This compounds across a kit. An MFT body + portrait zoom can weigh half of what an equivalent FF setup weighs.

**The tradeoff:** Smaller sensors collect less total light per exposure. This means:
- Reduced low-light performance (more noise at high ISO)
- Less shallow depth of field at equivalent framing and f-stop (a 42mm f/1.7 on MFT gives the DoF of roughly an 85mm f/3.4 on FF)

For people photography in decent light with burst shooting, the weight savings can outweigh these disadvantages. In low light or when maximum background separation is required, FF has a clear advantage.

## 7. Scoring Notes

Each vendor analysis will present data in consistent tables matching the criteria above. No weighted scoring or composite numbers — the data is presented as-is for the reader to evaluate based on their own priorities (weight, cost, image quality, autofocus performance, etc.).
